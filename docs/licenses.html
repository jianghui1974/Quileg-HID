1.2 本项目使用了什么、改了什么

复用（保留上游实现，做局部修改）：

  • server/hidagent/app.py：FastAPI 路由与应用装配 —— 改为 Quileg 首页、移除上游 Agent 路由、新增视频源/诊断接口（+104/−8）；
  • server/hidagent/screen.py：AirPlay 取帧 —— 增加多源路由与录屏帧率处理（+42/−6）；
  • server/hidagent/ 下 device.py、phone.py、vision.py、video.py、uvc.py：板子 TCP 协议、指针闭环手势、视觉定位、视频源路由 —— 基本保持上游实现；
  • hardware/hid_bridge/：「板子零逻辑 + 行命令」的协议设计被沿用，固件在 firmware/ 中重写；
  • control/pointer_calibrate.py：指针检测算法移植自上游 vision.py 的 pointer()。

不再使用（0.9.7 起已从运行路径与打包产物中移除）：

  • server/hidagent/agent.py（上游 LLM planner/actor）；
  • server/hidagent/llm.py（OpenAI 兼容客户端）；
  • server/hidagent/static/（上游网页 UI）。

这些文件仍保留在源码目录中，以满足 MIT 的完整性要求并便于追溯，但不参与构建、不随 DMG 分发。

2. UxPlay（GPL-3.0）

2.1 来源与版本

项值
仓库https://github.com/FDH2/UxPlay
版本UxPlay 1.74（构建于 2026-10，对应上游 master）
许可GNU General Public License v3.0

2.2 分发形式

  • Quileg HID 以独立可执行文件形式随 App 分发：Quileg HID.app/Contents/Frameworks/airplay/uxplay；
  • arm64 版为未经修改的上游构建；Intel 版套用了一个只有两行的构建补丁 uxplay-build.patch（见 Releases 附件）：把 PKG_CONFIG_PATH 的赋值从「覆盖」改成「环境优先」， 以便链接官方 universal GStreamer。该补丁不改变 UxPlay 的任何功能逻辑；对应源码 = 上游源码 + 该补丁（见 §2.3）；
  • Quileg HID 与 UxPlay 通过进程边界（命令行参数 + 标准输出管道）交互，两者是独立程序；GPL-3.0 的覆盖范围仅及 UxPlay 本身及其衍生作品，不延伸到 Quileg HID 的自有代码；
  • 随包同时提供 GPL-3.0 全文：licenses/GPL-3.0.txt。

2.3 对应源码（GPL-3.0 §6 履约）

按 GPL-3.0 的要求，我们向收到本产品的任何人提供 UxPlay 的对应源码：

  1. 同一下载页提供源码包：uxplay-master-source.tar.gz（与所分发二进制同版本的上游源码） 与 uxplay-build.patch（Intel 构建补丁）；
  2. 或访问上游仓库对应版本：https://github.com/FDH2/UxPlay；
  3. 若以上方式不可用，可书面请求 quileg@airdiode.com，我们在 3 年内免费提供完整源码（可选用物理介质，仅收取成本费）。

源码包的生成脚本见 packaging/fetch_uxplay_source.sh，发布时与 DMG 放在同一目录。

3. GStreamer 及其他随包原生库

UxPlay 依赖 GStreamer 及若干插件（LGPL-2.1）。这些库以未修改的动态库形式随 App 分发，位于 Quileg HID.app/Contents/Frameworks/airplay/：

  • 源码可从 https://gstreamer.freedesktop.org/source/ 与各插件上游获取；
  • LGPL-2.1 允许动态链接使用；如需替换其中任何库，可用同版本 ABI 兼容的构建替换对应 .dylib；
  • 完整的随包文件清单与版本，直接查看 App 包内的 Contents/Frameworks/airplay/。
